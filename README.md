**Solara: Last Light** — an original open-world crime sandbox in the spirit of GTA 6, written from scratch for the make.fun “Make GTA 6” bounty. Twenty-three named modules under `game/src/` drive a city, traffic, pedestrians, police, combat, missions, economy, HUD, minimap, audio and effects on a canvas renderer with a deterministic screenshot harness.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
